# 📋 Mini Task Application

A simple mobile task manager built with **React Native** and **SQLite** as a final project for BSIT 3A-DAY Android/iOS Mobile Development.

## 👩‍💻 Developer
**Joromo, Lovely J.**
BSIT 3A-DAY

## 📱 Features
- ✅ Create, Read, Update, and Delete tasks (CRUD)
- 🗄️ SQLite local database storage
- 🧭 Bottom Bar navigation
- 🎨 Pastel pink-purple UI design

## 🛠️ Tech Stack
- React Native (Expo)
- SQLite (expo-sqlite)
- Expo Router

## 📂 Screens
- **Home** – Welcome screen
- **Task List** – View all tasks
- **Add Task** – Create a new task
- **Task Detail** – View task info
- **Edit Task** – Update existing task

## 🚀 Installation
1. Clone the repo
```bash
   git clone <your-repo-url>
```
2. Install dependencies
```bash
   npm install
```
3. Run the app
```bash
   npx expo start
```

## 📦 APK Build
Built using EAS (Expo Application Services) for Android.
